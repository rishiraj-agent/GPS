**GPS — Geo & Phone Summary**

GPS is a privacy-focused Python CLI utility designed for Kali Linux and Kali Linux on WSL 2. It provides phone number validation, country calling codes, numbering-region information, available carrier metadata, and Google Maps search links for general geographic information. It also supports consent-based GPS access for the current device through a browser permission request.

**Features:**
- Phone number validation and formatting
- Country and region metadata lookup
- Available carrier and geographic information
- Google Maps search integration
- Permission-based live location for your own device
- Professional terminal interface with colored output
- Kali Linux and WSL 2 support
- Python-based, modular design

**Privacy First:** A phone number alone cannot reveal a person's exact live GPS location or private identity. GPS respects device permissions and is designed for legitimate, consent-based use.

**Technology:** Python 3 • Kali Linux • WSL 2 • Phonenumbers • Google Maps
